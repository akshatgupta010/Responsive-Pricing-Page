# Liquid Pricing

A modern SaaS pricing landing page inspired by a design reference and built following a YouTube tutorial. It features a fluid glassmorphism aesthetic, animated pricing toggle, and responsive layout.

## Features

- Interactive monthly/yearly billing switch
- Glass-style pricing cards with layered water effects
- Smooth animated price transitions
- 3D hover tilt effect on cards
- Responsive design for desktop and mobile screens
- Built with plain HTML, CSS, and JavaScript

## Project Structure

- `index.html` — page structure and pricing content
- `style.css` — main layout, card styling, and animations
- `base.css` — global theme, gradients, background effects, and base styling
- `script.js` — toggle behavior and card hover interactions

## Stack

- HTML
- CSS
- JavaScript
